# Toxic/Spam Filter

Content moderation service for [Pixel Maker](https://github.com/mynameisbenzo/level_builder).
Screens user-generated text (level titles, comments) before publishing.

**Status:** in progress

## Setup
    python -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements-dev.txt
